# Inside Grey Room v12.22 — Mobile UI / locale polish

This pass addresses the four regressions reproduced from iPhone screenshots without changing gameplay rules or server logic.

- Locale integrity: explicit French/English role labels and descriptions, plus a single persisted in-app locale switch.
- Header: reserved action lane on mobile so Settings and the notification bell cannot overlap.
- Door: notification chrome is hidden while the cinematic entrance is visible.
- Launch flow: every normal launch resolves Door -> Home. A saved room is offered through “Reprendre ma cellule” instead of being opened automatically.
- Settings: rebuilt as a structured, scroll-safe mobile sheet with General, Audio, Notifications, Privacy/Account, and Support/Legal sections.
- PWA/native parity: the same v12.22 UI runtime ships in the web, Android and iOS bundles; PWA cache is bumped.
