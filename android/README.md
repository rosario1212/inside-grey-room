# Inside Grey Room — Android V12.1

Ouvrir ce dossier `android/` dans Android Studio.

Le build copie automatiquement la V12.1 Web située à la racine du dépôt (`index.html`, `app-v11.js`, `styles-v11.css`, `manifest.webmanifest`, `service-worker.js` et `assets/`) dans les assets Android au moment du build.

Configuration : compileSdk 36, targetSdk 36, minSdk 26, Java 17.
